## How to navigate

<!--
This section is STATIC in the template — the regen script writes it verbatim
on every regen. Update by editing the template, then re-regen.
-->

**Session start auto-loads:** CLAUDE_MEMORY.md (operational shortcut) + this MAP (navigation).

**Topic-specific query → lazy load shard:**

1. Grep MAP for keywords matching user query (slug + stakeholder names + key terms)
2. Read matching shard from `memory/topics/<slug>.md`
3. Follow pointers in shard frontmatter (`related_decisions`, `related_briefs`, `related_knowledge`) for depth

**Need history → archives + git log:**

- Resolved items archive: `memory/archive/<YYYY-MM>.md`
- Per-decision audit trail: `memory/decisions/<date>-<slug>.md`
- Past meeting prep: `memory/briefs/<date>_<event>.md`

**Need canonical → knowledge:**

- `knowledge/<constitution>.md` is single source of truth
- `knowledge/INDEX.md` lists all knowledge docs

**Need to write something → classify first** (see `memory/README.md` "Classification rule"):

- Decision → `memory/decisions/`
- Historical artifact → `memory/archive/` or `deliverables/`
- Canonical fact → constitution patch proposal
- Operational current state → `CLAUDE_MEMORY.md` (then likely graduate to shard)
